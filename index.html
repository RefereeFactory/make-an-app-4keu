    How it works

    Simple, private, and always remembered.

    1. Add a task — jot what needs doing, tie it to a customer, and set a due date if it helps.
    2. Stay organised — use the chips to filter active, done, or soon-due tasks, and the search box to find anyone quickly.
    3. Tick it off — tap the circle to mark a task complete. Edit or delete anything with the row buttons.
    4. Always saved — every change is stored safely in the cloud, so your list is right where you left it next time you visit.
